# PractoCore downloads

Installers for **PractoCore**, practice management and legal AI for Ugandan law firms, by PractoCore Technologies Limited.

**Download from [www.practocore.com](https://www.practocore.com).** The site always links the newest version.

This repository holds release files only. The application's source code is not published here.

## Latest release

| Platform | File |
|---|---|
| Windows | `PractoCore-windows-x64-setup.exe` |
| macOS (Apple silicon) | `PractoCore-macos-arm64.dmg` |
| macOS (Intel) | `PractoCore-macos-x64.dmg` |
| Linux | `PractoCore-linux-x86_64.AppImage`, `.deb`, `.rpm` |
| Android | `PractoCore-android.apk` |

All files are on the [latest release](../../releases/latest).

The desktop builds are not yet code-signed. On first launch, Windows may show a SmartScreen prompt (choose **More info → Run anyway**), and macOS may ask you to open the app from Finder with **right-click → Open**.
